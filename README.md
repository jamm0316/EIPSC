# EIPSC — 정처기 실기 카드 (PWA)

정보처리기사 실기 약점 카드를 폰에서 바로 여는 정적 PWA. 프레임워크·빌드 없이 `index.html`, `styles.css`, `app.js`, `data/cards.json`만으로 동작한다.

배포: https://jamm0316.github.io/EIPSC/

## 기능
- **하루 제한 없음** — 필터(종류·단원)에 맞는 카드를 한 바퀴씩 계속 돈다. 바퀴가 끝나면 [한 바퀴 더].
- **회독 체크 0~5** — 뒤집고 확인한 뒤 [봤음 +1]. 5회를 채우면 완료로 빠진다([5회 채운 카드도 보기]로 다시 포함). 회독 점 1~5를 직접 눌러 숫자를 고칠 수 있다(같은 점을 다시 누르면 1 감소).
- 순서: 적게 본 카드 → 예전 카드 앱에서 틀렸던 카드(`ng - ok`) → 단원 순. [섞기]를 켜면 같은 회독 수 안에서 무작위.
- 기록은 기기 브라우저(localStorage)에 저장된다. 하단 [기록 백업 · 초기화]에서 백업 코드 복사/붙여넣기.
- 오프라인: 한 번 열면 셸과 카드가 캐시된다. 카드 데이터는 네트워크 우선이라 새 카드가 올라오면 다음 실행 때 반영.

## 홈 화면에 추가
- iPhone: 사파리로 열고 공유(□↑) → 홈 화면에 추가
- Android: 크롬 메뉴(⋮) → 홈 화면에 추가 / 앱 설치
- 안내 모달은 처음 한 번만 뜬다. 다시 보려면 `?a2hs=1`.

## 카드 갱신
카드 원본은 튜터링 세션의 카드 앱 db(`cards` 컬렉션)다. 새 카드가 생기면:

```bash
# db를 JSON 파일들로 export한 폴더를 넘긴다 (retired 제외)
python3 tools/build_cards.py <export-dir>
```

`data/cards.json`이 다시 만들어진다. 커밋·푸시하면 Pages에 반영된다. 회독 기록은 카드 id 기준이라 유지된다.

## 정적 파일을 바꿀 때
`sw.js`의 `CACHE_VERSION`과 `index.html`·`sw.js`의 `?v=` 값을 함께 올린다.

## 로컬 실행
```bash
python3 -m http.server 8080   # http://localhost:8080
```
